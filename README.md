# MattressSalesApp
Java application for mattress sales business

## Project Overview
This project contains two main parts:
1. Console sales report application using arrays, interface, classes and JUnit unit tests
2. Swing GUI sales calculator with validation, clear and exit buttons

## Tech Stack
- Java
- Apache NetBeans
- JUnit

## How to run
1. Open the project in Apache NetBeans
2. Run MainApp.java for the console report
3. Run ProductApp.java to launch the GUI
